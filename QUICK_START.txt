═══════════════════════════════════════════════════════════════════════════════
 TESTING PREDICTIONS (PYTHON)
═══════════════════════════════════════════════════════════════════════════════

1. Test the prediction model:
   
   python predict_pollution.py
   
   This runs 4 test scenarios and shows predictions


2. Test recommendations:
   
   python mitigation_suggestions.py
   
   This shows recommendations for 3 different scenarios


3. Custom Python script:

   from predict_pollution import PollutionPredictor
   from mitigation_suggestions import MitigationRecommender
   
   # Load model
   predictor = PollutionPredictor('model/pollution_model.pkl')
   
   # Make prediction
   result = predictor.predict({
       'pH': 7.0, 'DO': 6.5, 'turbidity': 2.0,
       'temperature': 15.0, 'conductivity': 500.0,
       'nitrate': 3.0, 'phosphate': 0.2,
       'bod': 2.0, 'cod': 10.0
   })
   
   print(f"Risk: {result['pollution_risk']}")
   print(f"Confidence: {result['confidence']}%")
   
   # Get recommendations
   recommendations = MitigationRecommender.recommend(result)
   for rec in recommendations:
       print(rec)


═══════════════════════════════════════════════════════════════════════════════
 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

ISSUE: "Python not found" or "command not recognized"
SOLUTION: 
  - Ensure Python is installed and in PATH
  - Use "python3" instead of "python" on Mac/Linux
  - Check: python --version

ISSUE: "ModuleNotFoundError: No module named 'pandas'" (etc.)
SOLUTION:
  - Install missing packages: pip install -r requirements.txt
  - Or individually: pip install pandas numpy scikit-learn etc.

ISSUE: "FileNotFoundError: dataset/sensor_data.csv"
SOLUTION:
  - Run: python generate_dataset.py
  - Creates the dataset automatically

ISSUE: "FileNotFoundError: model/pollution_model.pkl"
SOLUTION:
  - Run: python train_model.py
  - Trains and saves the model

ISSUE: "Streamlit command not found"
SOLUTION:
  - Install: pip install streamlit streamlit-folium
  - Then: streamlit run app.py

ISSUE: "Address already in use" when starting Streamlit
SOLUTION:
  - Port 8501 is already in use
  - Run on different port: streamlit run app.py --server.port 8502
  - Or stop the other process

ISSUE: "XGBoost not available" warning
SOLUTION:
  - Optional: pip install xgboost
  - System uses Gradient Boosting as fallback
  - No impact on functionality
