3. COMPONENT DESCRIPTIONS
═════════════════════════════════════════════════════════════════════════════

A. DATASET GENERATOR (generate_dataset.py)
────────────────────────────────────────────

Purpose: Create synthetic water quality sensor data

Function: generate_sensor_data(n_samples=10000)
  Input:
    - n_samples: Number of records to generate
  
  Process:
    1. Generate 10,000 hourly timestamps (Jan 2023 - Jun 2023)
    2. Generate geographic coordinates (40.5°N, -73.8°W region)
    3. Generate realistic sensor readings with distributions:
       - pH follows normal distribution (mean=7.0, std=0.8)
       - DO follows normal distribution (mean=6.5, std=1.5)
       - Others use exponential or normal distributions
    4. Randomly assign event types (70% normal, 10% each for 3 events)
    5. Calculate pollution_level based on parameter values
    6. Return DataFrame with 14 columns
  
  Output:
    - 10,000-row pandas DataFrame
    - Saved to: dataset/sensor_data.csv
    - Columns: timestamp, lat, lon, pH, DO, turbidity, temp,
              conductivity, nitrate, phosphate, bod, cod,
              event_type, pollution_level


B. MODEL TRAINER (train_model.py)
──────────────────────────────────

Purpose: Train and select best ML model

Class: ModelTrainer

Methods:
  - load_data(): Load dataset from CSV
  - prepare_data(): Feature scaling and label encoding
  - train_random_forest(): Train RF with 100 trees
  - train_gradient_boosting(): Train GB with 100 estimators
  - train_xgboost(): Train XGB with 100 estimators
  - select_best_model(): Choose model with highest accuracy
  - save_model(): Serialize best model and preprocessors

Output:
  - Trained model saved to: model/pollution_model.pkl
  - Contains: Model object, StandardScaler, LabelEncoder, model_name


C. POLLUTION PREDICTOR (predict_pollution.py)
──────────────────────────────────────────────

Purpose: Make real-time water quality predictions

Class: PollutionPredictor

Methods:
  - __init__(model_path): Load saved model and preprocessors
  - predict(sensor_readings): Make single prediction
  - predict_batch(readings_list): Make batch predictions

Prediction Process:
  1. Receive 9 sensor parameter values
  2. Arrange in feature order: [pH, DO, turbidity, ...]
  3. Scale features using fitted StandardScaler
  4. Pass scaled features to trained model
  5. Extract class prediction and probabilities
  6. Calculate confidence (max probability × 100)
  7. Decode class label back to string (Good/Moderate/Bad)
  8. Return comprehensive result dictionary

Output:
  {
    'pollution_risk': 'Good|Moderate|Bad',
    'confidence': 95.23,
    'probabilities': {'Good': 95.23, 'Moderate': 4.12, 'Bad': 0.65},
    'model_used': 'XGBoost'
  }


D. MITIGATION RECOMMENDER (mitigation_suggestions.py)
───────────────────────────────────────────────────────

Purpose: Generate actionable mitigation recommendations

Class: MitigationRecommender

MITIGATION_RULES Dictionary:
  For each parameter (turbidity, nitrate, phosphate, DO, bod, cod, pH):
    - threshold: Alert level
    - issue: Problem description
    - recommendations: List of 5-7 mitigation strategies

Method: recommend(sensor_data)
  Input: Dict with sensor parameters and pollution_risk
  
  Process:
    1. Check overall pollution risk level
       → CRITICAL if risk = 'Bad'
       → HIGH if risk = 'Moderate'
       → LOW if risk = 'Good'
    
    2. For each parameter:
       → Check if value exceeds threshold
       → If yes, add specific recommendations
       → Include priority level and action steps
    
    3. Return ranked list of recommendations
  
  Output: List of recommendation dictionaries with:
    - Priority level (CRITICAL/HIGH/MEDIUM/LOW)
    - Parameter name and current value
    - Issue description
    - 5-7 actionable mitigation strategies

4. ML PREDICTION PIPELINE
═════════════════════════════════════════════════════════════════════════════

INPUT LAYER
───────────
9 Sensor Parameters:
  └─ [pH, DO, turbidity, temperature, conductivity, 
      nitrate, phosphate, bod, cod]

PREPROCESSING LAYER
───────────────────
  ├─ StandardScaler (fitted during training)
  │  └─ Normalize each feature to mean=0, std=1
  │
  └─ Feature Arrangement
     └─ Ensure correct order matching training data

INFERENCE LAYER
───────────────
  ├─ Input: Scaled features [9 values]
  │
  ├─ Model: XGBoost Classifier
  │  └─ 100 gradient boosting trees
  │  └─ Multi-class classification
  │  └─ Outputs class predictions & probabilities
  │
  └─ Output: 
     ├─ Predicted class (0/1/2)
     ├─ Class probabilities [p_good, p_moderate, p_bad]

POST-PROCESSING LAYER
─────────────────────
  ├─ Probability Extraction
  │  └─ Select max probability
  │  └─ Convert to percentage (×100)
  │
  ├─ Class Decoding
  │  └─ 0 → 'Good'
  │  └─ 1 → 'Moderate'
  │  └─ 2 → 'Bad'
  │
  └─ Probability Mapping
     └─ Assign probabilities to class names

OUTPUT LAYER
────────────
  {
    'pollution_risk': 'Good|Moderate|Bad',
    'confidence': 0-100,
    'probabilities': {
      'Good': percentage,
      'Moderate': percentage,
      'Bad': percentage
    },
    'model_used': 'XGBoost|Gradient Boosting|Random Forest'
  }

POLLUTION CLASSIFICATION LOGIC
───────────────────────────────

  1. Get pollution_level from dataset
  2. Assign color:
     IF pollution_level == 'Good':
       color = 'green'
     ELIF pollution_level == 'Moderate':
       color = 'orange'
     ELSE:  # 'Bad'
       color = 'red'
  3. Create CircleMarker with color
  4. Add popup with sensor details
  5. Add to Folium map

6. MITIGATION ENGINE LOGIC
═════════════════════════════════════════════════════════════════════════════

RECOMMENDATION GENERATION ALGORITHM
───────────────────────────────────

Input: sensor_data dict with parameters and pollution_risk

Step 1: Risk Level Assessment
  IF pollution_risk == 'Bad':
    Priority = CRITICAL
    Action = Issue health advisory immediately
  ELIF pollution_risk == 'Moderate':
    Priority = HIGH
    Action = Increase monitoring & prepare mitigation
  ELSE:
    Priority = LOW
    Action = Continue routine monitoring

Step 2: Parameter-Specific Analysis
  FOR each sensor parameter:
    IF parameter_value > threshold:
      Add parameter-specific recommendations
      Set appropriate priority level

Step 3: Rule Matching
  
  Turbidity Check:
    IF turbidity > 15 NTU:
      Issue: High suspended solids
      Actions:
        1. Install rapid sand filtration
        2. Deploy sedimentation tanks
        3. Install coagulation units
        4. Increase monitoring
        5. Control sediment sources
  
  Dissolved Oxygen Check:
    IF DO < 4 mg/L:
      Issue: Hypoxic conditions (CRITICAL)
      Actions:
        1. Install mechanical aeration
        2. Improve water circulation
        3. Reduce organic pollution
        4. Restore riparian vegetation
        5. Improve wastewater treatment
  
  [Similar logic for Nitrate, Phosphate, BOD, COD, pH]

Step 4: Aggregation & Ranking
  1. Collect all recommendations
  2. Sort by priority (CRITICAL > HIGH > MEDIUM > LOW)
  3. Sort by parameter criticality
  4. Remove duplicates
  5. Return ranked list

Output: List of recommendation objects
  {
    'priority': 'CRITICAL|HIGH|MEDIUM|LOW',
    'parameter': 'Parameter Name',
    'value': current_value,
    'issue': problem_description,
    'recommendations': [action1, action2, ...]
  }
